# Datheon Full-Stack Web Development Internship Matrix

Welcome to the central repository tracker for my 4-week project-based cohort with Datheon (AI Systems and Automation Studio).

This workspace houses my completely isolated production-grade project systems. All tasks are engineered using a uniform, high-performance tech stack focused on modern component architectures, type safety, and clean layout scaling.

## 🛠️ Uniform Engineering Tech Stack

- **Core Frameworks:** Next.js (App Router) and React (ES6+)
- **Type Security:** TypeScript
- **Styling Architecture:** Tailwind CSS and Centralized CSS Variables
- **Development Environment:** WSL2 (Windows Subsystem for Linux) running Ubuntu Linux
- **Deployment Platform:** Vercel Continuous Integration Pipeline

## 📁 Repository Workspace Layout

The root folder structure isolates each submission block cleanly to ensure simple grading evaluation:

- `task1-portfolio/` : Beginner Level showcase featuring structured layout sections, an active dark/light mode toggle node, responsive mobile hamburger navigation, and deep-dive documentation project modals.
- `task3-weather/` : Intermediate Level telemetry application utilizing asynchronous operations, native Fetch API hooks, and defensive client-side error handling arrays.
- `task4-ecommerce/` : Intermediate Level e-commerce engine driving global state management via the React Context API with persistent cart calculation algorithms.

## 🚀 Workspace Operational Verification

Each task folder is completely standalone. To evaluate or launch any specific project system locally inside your WSL2 terminal environment, navigate directly into that folder block:

```bash
# 1. Move into the targeted task directory
cd task1-portfolio

# 2. Install independent local dependencies
npm install

# 3. Spin up the hot-reloading local development engine
npm run dev
```

Open `http://localhost:3000` inside your web browser instance to review the active project build.
